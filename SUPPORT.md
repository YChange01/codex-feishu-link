# Getting help

- **Installation and usage:** start with the [user guide](./docs/general/user-guide.md) and [quick start](./QUICKSTART.md).
- **How to contribute:** see [CONTRIBUTING.md](./CONTRIBUTING.md).
- **Bug reports and feature requests:** use the repository's GitHub issue forms and include the version, operating system, steps to reproduce, and expected behavior. Remove credentials and personal data from logs.
- **Security vulnerabilities:** do not open a public issue; follow [SECURITY.md](./SECURITY.md).
