# Security policy

## Reporting a vulnerability

Please do not report exploitable vulnerabilities in public issues. Use GitHub's **Report a vulnerability** action in the repository's Security tab to contact the maintainers privately. Include the affected version, impact, reproduction steps, and any relevant logs with secrets removed.

If private vulnerability reporting is unavailable, contact the repository maintainers through GitHub and request a private reporting channel. Do not include credentials, tokens, session transcripts, or personal data in the initial report.

## Supported versions

Security fixes are made against the latest supported release. Until a formal support matrix is published, users should upgrade to the latest release before reporting an issue.

## Handling sensitive data

This project connects a local AI coding environment to Feishu. Treat bot credentials, local Codex/Claude configuration, workspace contents, session transcripts, and diagnostic logs as sensitive. Redact them before sharing diagnostics or issue reports.
